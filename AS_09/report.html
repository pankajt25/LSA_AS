🛡️ System Maintenance & Production Hygiene Standards

Temporary Storage Management Practices:

  • systemd-tmpfiles Integration: Modern Linux systems manage /tmp and /var/tmp via systemd-tmpfiles configuration (e.g. d /tmp 1777 root root 10d in /etc/tmpfiles.d/custom-tmp.conf).
  • Sticky Bit Security: Temporary directories must enforce the sticky bit (chmod +t /tmp or mode 1777) to prevent users from unlinking or renaming other users' files.
  • Scheduled Execution: Schedule routine maintenance via cron: 0 2 * * * /path/to/temp_cleaner.sh -d 7 --delete.
  • Dry-Run Verification: Always run with --dry-run first before introducing new cleanup policies to production directories.
