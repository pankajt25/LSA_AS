🔍 Architecture, Methodology & System Design
ADMINISTRATOR SPECIFICATION

⚡ Why --sort=-%cpu

GNU ps sorts entries internally in memory before writing to stdout. The leading minus signifies descending order. This eliminates piping across external sort, avoids broken multi-column wrapping, prevents float locale errors, and is immune to SIGPIPE errors under set -eo pipefail.

📊 Column Set Rationale

PID uniquely identifies target tasks; PPID reveals ancestry and process trees; USER isolates daemon vs unprivileged workloads; %CPU tracks computational load; %MEM isolates memory thrashing or leak correlation; COMM provides uniform width without long arguments.

🍎 Cross-Platform Resilience

Detects platform via uname -s. Linux executes native GNU ps --sort=-%cpu. macOS BSD ps automatically switches to ps -r descending CPU flag, ensuring true cross-platform portability without mock or placeholder data.

🛡️ Sandboxing & Read-Only Safety

Strictly inspection-only. Zero processes killed, reniced, or signaled. Filesystem writes are 100% contained within AS_19/ (audit log and HTML report). Zero modifications to /etc, block devices, or user directories.
