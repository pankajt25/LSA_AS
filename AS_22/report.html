⚡ Parallel vs. Sequential Concurrency

Sequential execution iterates over targets one-by-one with runtime O(N × timeout). If 5 hosts are unreachable with a 2s timeout, sequential probing stalls for 10+ seconds.

  • Parallel Model: Probes are launched concurrently as subshells (&) writing to numbered slot files, synchronized via bash wait.
  • Wall-Clock Scalability: Total runtime collapses to O(timeout) (~2-3 seconds for entire fleet).
  • Deterministic Order: Preserves inventory configuration ordering upon table rendering.

🔍 Network Diagnostic Nuance

Why do certain targets report DOWN in this live test?

  • 192.168.32.1 (WSL2 Gateway): The default gateway is the Hyper-V virtual switch adapter. Windows Defender Firewall drops incoming ICMP Echo Requests by default, while routing external WAN traffic normally.
  • 192.0.2.1 (TEST-NET-1): Reserved by RFC 5737 for documentation and benchmarking. It is intentionally non-routable on the public Internet, verifying proper 100% loss trapping.

🛠️ Cross-Platform Portability

Network probe flags diverge across Unix distributions and Windows environments:

  • Linux (iputils): ping -c 2 -W 2 <host> (packet count and hard timeout).
  • macOS (BSD): ping -c 2 -t 2 <host> (timeout flag -t).
  • Windows Native: ping -n 2 -w 2000 <host> (count -n and millisecond timeout -w).
