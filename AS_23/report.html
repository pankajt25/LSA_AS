⚖️ Architectural Rationale: iproute2 (ip) vs Legacy net-tools (ifconfig/route)

Engineering Deep Dive
Architectural Metric Modern iproute2 (ip suite) Legacy net-tools (ifconfig / route)
Kernel Communication AF_NETLINK Sockets: High-throughput, asynchronous, event-driven kernel datagram communication. Synchronous ioctl(): Slow, inflexible system calls incapable of conveying rich modern link state.
Multi-IP Handling Native First-Class Objects: Dozens of addresses bind directly to a single link without artificial alias syntax. Archaic Alias Hack: Required virtual sub-interfaces (eth0:0, eth0:1); hides secondary unlabeled IPs.
Subnet Representation Native CIDR Notation: Standard prefix length notation (/24, /20, /64) used universally. Dotted Decimal Masks: Verbose netmask 255.255.255.0 inherited from legacy classful era.
Namespaces & Containers Complete Netns Integration: Full control of virtual ethernet, network namespaces, bridges, and VRFs. Zero Namespace Awareness: Incapable of inspecting or isolating containerized networking environments.
Policy Routing & FIB Policy Routing (PBR): Manages multiple routing tables, traffic selectors, metrics, and multipath rules. Single Static Table: Strictly limited to the default kernel destination routing table.
Distribution Status Default Standard: Actively developed in lockstep with the Linux kernel across all enterprise distributions. Deprecated: Officially deprecated in ~2009; omitted from Ubuntu, Debian, RHEL, and Fedora default installs.
